El juego corre en un servidor local de Wollok.

Esta página no puede servir el juego por sí sola: para verlo acá tenés que tener el servidor levantado en tu máquina, corriendo wollok run dentro del repo del juego. Cuando esté escuchando en {{ config.gameLocalUrl }}, el juego aparece abajo. Si ves un recuadro vacío o un error, el servidor no está corriendo.
